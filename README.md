# 設計製図 作業時間計測タイマー（PWA）

Android のホーム画面から、全画面・オフラインで起動できる計測タイマーです。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨格とスタイル |
| `app.js` | **計測項目（CONFIG / TASKS）とロジック。編集するのはこのファイル** |
| `manifest.json` | アプリ名・アイコン・全画面設定 |
| `sw.js` | オフライン担当（Service Worker） |
| `icons/` | ホーム画面アイコン 3種 |

## 導入手順

### 1. 配信する

**HTTPS での配信が必須**です。`file://` でローカルに開くと Service Worker が動かず、オフライン化とホーム画面へのインストールができません。

GitHub Pages の例：

1. GitHub で新しいリポジトリを作る（Public）
2. この `seizu_timer_pwa` の中身（`index.html` などを直下に）をアップロードする
3. Settings → Pages → Source を `main` ブランチの `/ (root)` に設定
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開ける

Netlify Drop（フォルダをドラッグするだけ）や Cloudflare Pages でも同じことができます。

### 2. ホーム画面に追加する

1. Android の Chrome で上記 URL を開く
2. 右上のメニュー → **アプリをインストール**（または「ホーム画面に追加」）
3. 以降はアイコンから、URL バーなしの全画面で起動する

初回に一度オンラインで開けば、次からは機内モードでも動きます。

## 計測項目を変える

`app.js` の冒頭にある `CONFIG` と `TASKS_SRC` だけを書き換えます。

```js
const CONFIG = { examTitle: "一級建築士", subject: "設計製図", totalMinutes: 390 };

const TASKS_SRC = [
  { phase: "エスキス", name: "課題文読解・条件整理", std: 20 },
  { phase: "作図", sheet: "平面図", name: "柱の図示", std: 5 },
];
```

- `phase` … フェーズ名。「フェーズ単体」の選択肢が自動で作られる
- `sheet` … 図面名（任意）。付けると「図面単体」の計測と図面別集計が有効になる
- `std` … 標準時間（分）。`0` にすると差分を出さず実測のみ記録する
- `id` は自動で振られるので不要。記載順がそのまま計測順になる

### 更新を反映させる

`app.js` を書き換えたら、**`sw.js` の `CACHE` の版番号を必ず上げてください。**

```js
const CACHE = "seizu-timer-v2";  // v1 から上げる
```

版番号が同じままだと、端末に保存された古いファイルが使われ続け、変更が反映されません。上げるとアプリを開き直した際に新しいファイルが読み込まれます。

## 記録について

計測結果は端末の localStorage に保存されます（最大100件）。

- ブラウザの「サイトデータを削除」を行うと**記録は失われます**
- 端末間では同期されません
- 残しておきたい結果は、結果画面の「結果をテキストで書き出す」でコピーしてください

## 仕様メモ

- 経過時間は `Date.now()` の絶対時刻から毎回算出しているため、画面が消えても復帰時に正しい時間へ自動補正されます
- Wake Lock API で画面スリープを抑止します（対応端末のみ）
- 項目の標準時間を超えると、色が反転して1回だけ振動します
- 「スキップ」した項目は0分で記録され、その時点までの経過時間は次の項目へ繰り越されます
- 一時停止中の時間は総時間から除外し、中断時間として別途記録します
